> 將抽象的十進位位值與代數拆解，轉換為生動的**幾何積木方塊分組**與**逐步算式推導動畫**，讓學生一眼看懂「為什麼倍數判別法會成立」。

## ✨ 核心特色

1. **幾何方塊視覺化拆解**
   - **個位、十位（條狀）、百位（百數板）、千位以上（3D 立體方塊 SVG）** 實體呈現。
   - 動態演示「整除部分分組打包」與「多出來或不足的方塊進行飛行動畫集中統計」。
2. **算式同步逐步推導**
   - 右側同步顯示嚴謹代數拆解步驟（例如 $100 = 99 + 1$、$1000 = 1001 - 1$）。
   - 步驟間具備平滑過渡高亮，老師講課免板書、學生理解無門檻。
3. **雙展示模式（響應式）**
   - 📺 **投影模式（Projector）**：左右分欄（大方塊圖 ＋ 大字體算式），適合電子白板與教室大型觸控螢幕。
   - 📱 **手機模式（Mobile）**：垂直最佳化排版，學生平板或家長手機隨開即練。
4. **手勢縮放與大圖／大算式切換**
   - 支援滑鼠滾輪、觸控雙指縮放（Pinch-to-zoom）與平移拖曳。
   - 一鍵切換「⤢ 大圖模式」或「⤢ 大算式模式」，聚焦細節。
5. **自由輸入與智慧隨機出題**
   - 可直接在輸入框輸入任意數值（支援 6 位數，7 的倍數支援至 12 位數）。
   - 內建精選題庫按鈕與 🎲 隨機出題功能（自動包含整除與不整除對照案例）。
6. **URL 參數直接分享**
   - 老師可直接產生特定題目的連結分享至 Google Classroom、Padlet 或 LINE：
     - `?r=11&n=9724`（演示 11 的倍數）
     - `?r=7&n=366415`（演示 7 的三位分節法）
     - `?r=3&n=1234`（演示 3 的倍數餘數原理）

## 📐 數學判別法原理總覽

| 規則 | 判別口訣 | 幾何與十進位拆解原理 |
| :--- | :--- | :--- |
| **2 的倍數** | 個位數是 $0, 2, 4, 6, 8$（偶數） | $10 = 2 \times 5$、$100 = 2 \times 50$，十位以上的數一定能被 $2$ 整除，故只需檢視個位。 |
| **4 的倍數** | 末兩位數是 $4$ 的倍數（或 $00$） | $100 = 4 \times 25$、$1000 = 4 \times 250$，百位以上的數必能被 $4$ 整除，故只需檢視末兩位。 |
| **8 的倍數** | 末三位數是 $8$ 的倍數（或 $000$） | $1000 = 8 \times 125$，千位以上的數必能被 $8$ 整除，故只需檢視末三位。 |
| **3 的倍數** | 各個數位數字和是 $3$ 的倍數 | $10 = 9 + 1$、$100 = 99 + 1$、$1000 = 999 + 1$，將每個位值拆出 $3$ 的倍數後，各剩下 $1$ 個方塊，集合後即為「數字和」。 |
| **9 的倍數** | 各個數位數字和是 $9$ 的倍數 | 原理同 $3$ 的倍數：$9, 99, 999$ 皆為 $9$ 的倍數，剩下的方塊總數就是各位數字和。 |
| **11 的倍數** | 「奇數位數字和」與「偶數位數字和」之差為 $11$ 的倍數或 $0$ | $10 = 11 - 1$（偶數位少 1）、$100 = 99 + 1$（奇數位多 1）、$1000 = 1001 - 1$（偶數位少 1），「多出來的」與「不足的」互相抵消。 |
| **7 的倍數**<br>*(補充)* | **三位分節法**：從個位起每三位一節，「奇數節和 − 偶數節和」為 $7$ 的倍數或 $0$ | 因為 $1001 = 7 \times 11 \times 13$，而 $1000 = 1001 - 1$、$10^6 = 1001 \times 999 + 1$，一加一減交替抵消！同一個差亦可用於判別 $11$ 與 $13$。 |

## ⌨️ 鍵盤快捷鍵指南

在電腦或連接外接鍵盤的觸控大屏上，可透過以下快速鍵操作：

| 快捷鍵 | 功能 |
| :---: | :--- |
| `→` / `PageDown` / `Space` / `Enter` | **下一步**（觸發分組與飛行動畫） |
| `←` / `PageUp` / `Backspace` | **上一步** |
| `P` | **自動連續播放** / 暫停 |
| `+` / `=` | 放大視圖 |
| `-` / `_` | 縮小視圖 |
| `0` | 還原 100% 縮放比例 |
| `G` | 切換 **大圖模式** |
| `E` | 切換 **大算式模式** |
| `F` | 切換 **全螢幕模式** |

## 🚀 本地端運行

本專案為零依賴的純原生 Web 應用（HTML5 + CSS3 + Vanilla JavaScript），無須 Node.js 或建置打包流程：

```bash
# 複製專案
git clone https://github.com/cconecone-cmyk/divisibility-rules.git

# 進入資料夾
cd divisibility-rules

# 直接用任何瀏覽器打開 index.html
start index.html # Windows
open index.html  # macOS
```
